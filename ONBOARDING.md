## Your Setup Checklist

### Codebases
- [ ] empty — https://github.com/webfiks/empty

### MCP Servers to Activate
- [ ] GitHub — repos, PRs, issues, Actions. Connect GitHub at claude.ai (Settings → Connectors) and install the Claude GitHub App on the repo.
- [ ] Vercel — projects, deployments, domains, logs. Add the Vercel connector at claude.ai and sign in with the team Vercel account.
- [ ] Supabase — databases, SQL, migrations, edge functions. Add the Supabase connector at claude.ai and authorize the team org.
- [ ] Semrush — SEO, keywords, backlinks, traffic research. Add the Semrush connector at claude.ai (needs a Semrush subscription).
- [ ] Context_dev — web search, scraping, brand data. Add the Context.dev connector at claude.ai.

### Skills to Know About
- /context — shows what's using the session's context window; check it at the start of long tasks.
- /insights — generates a report on how you use Claude Code, with suggestions.
- /doctor — health-checks your Claude Code setup and proposes cleanups.
- /skill-doctor — lists loaded skills, their context cost, and which ones are unused.
